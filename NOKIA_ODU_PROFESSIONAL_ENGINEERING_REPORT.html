Binary Reverse Engineering & 5RDP Container Decryption

Cryptographic Pipeline

The 5RDP Container Format

Nokia firmware archives (such as AOD311NK_R6.0.bin) are encrypted container images. The container begins with a 256-byte header: 

Offset 0x00: 52 44 50 35 ("5RDP" Magic Identifier)
Offset 0x04: Target Hardware String ("AOD311NK" / "5G32-A")
Offset 0x18: 16-Byte AES Initialization Vector (IV)
Offset 0x28: SHA-256 Digest of Decrypted Partition Table
Offset 0x48: Encrypted Partition Payloads (AES-128/256-CBC)

The BATIDecrypt Decompilation Overview

/usr/bin/BATIDecrypt reads standard input, parses the container manifest, retrieves the on-chip platform key, and performs cryptographic streaming: 

int main(int argc, char **argv) {
    if (read(0, &hdr, sizeof(hdr)) < 256) exit(1);
    if (memcmp(hdr.magic, "5RDP", 4) != 0) exit(0x10);
    // Derive key from platform hardware ID
    EVP_DecryptInit_ex(ctx, EVP_aes_128_cbc(), NULL, key, hdr.iv);
    while ((n = read(0, in_buf, 4096)) > 0) {
        EVP_DecryptUpdate(ctx, out_buf, &out_len, in_buf, n);
        write(1, out_buf, out_len); // Pipes to /bin/burn
    }
}

Watchdog Supervision & VFS Bind-Mount Virtualization

Non-Destructive Override

To stop the 300-second hardware reset and PCD short-boot lockout without modifying the dm-verity protected rootfs, we use Linux Virtual File System (VFS) in-memory mount redirection:

The Supervision Trap

  • Hardware Watchdog (/dev/watchdog1): Supervised by wd_pcdtest.sh and wdtest.sh. Trips after 300 seconds if unpetted.
  • PCD Deadman Daemon: If Airtel IMS/ACS is unreachable, postaction.sh triggers an emergency reset (reboot -f).
  • Rapid Reboot Counter (/configs/uptime): If 3 boots occur with uptime under 700s, the bootloader triggers an automatic slot flip.

The Non-Destructive Resolution

# 1. Persistent neutral success stub on UBIFS
cat << 'EOF' > /systemrw/dummy_ok.sh
#!/bin/sh
exit 0
EOF
chmod 755 /systemrw/dummy_ok.sh

# 2. Bind mount over all reboot scripts
mount --bind /systemrw/dummy_ok.sh /bin/wd_pcdtest.sh
mount --bind /systemrw/dummy_ok.sh /etc/watchdog.d/wdtest.sh
mount --bind /systemrw/dummy_ok.sh /bin/postaction.sh

# 3. Disarm rapid reboot tracker in flash
printf '0:700\n0:700\n0:700\n0:700\n0:700\n' > /configs/uptime
Zero dm-verity Conflict: Because mount --bind operates purely at the in-memory Linux VFS dentry layer, the physical SquashFS blocks on mtd33 remain completely unmodified. The kernel Merkle tree matches 100%, preventing integrity panics.
