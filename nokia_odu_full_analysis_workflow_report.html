⏱️ Workflow 3: Nokia PCD Hardware Watchdog & Deadman Neutralization

Root Cause of 300s & Rapid Reboot Loops Security Traps

(b) CellularWanMgr calls /bin/postaction.sh which triggers hard reboot -f.
